# 3D Lighting Studio

Environment, directional, point and spot lights.

## What to inspect

- WorldEnvironment3D
- PointLight3D
- SpotLight3D

## Try it

1. Open `scenes/main.vscene` in the editor.
2. Explore the Scene dock, select a node and inspect its properties.
3. Use the 2D or 3D workspace depending on the project.
4. Start the Game View or run the project to examine runtime behavior.
5. Change a parameter, save, and compare the result.

A starter scene illustrates engine features; gameplay systems not explicitly scripted in the scene are exercises for you to implement.
