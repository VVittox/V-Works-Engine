# V Works Engine 0.9.0 — большие сцены и перемещение в 3D

Обновление исходников движка 0.8.0 из присланного архива. Основные изменения — пространственная сетка физики, кэш 3D-геометрии, отсечение невидимых мешей и новый манипулятор редактора. Форматы `.vscene` / `.vproject` и API `position`, `rotation`, `scale` сохранены.

## Запуск

Windows: открой эту папку, запусти `setup_windows.bat`, затем `start_editor.bat`. Установка создаёт своё окружение Python 3.12. Выбери свой проект в окне редактора. Для нового EXE запусти `rebuild_editor_windows.bat`: получится `dist/V Works Engine/V Works Engine.exe`.

Linux/macOS: создай venv, установи `requirements.txt`, выполни `python launch_editor.py`. Здесь подготовлены исходники; готового нового Windows EXE нет. Виртуальное окружение, старые сборки и кэши из исходного архива не включены — их создают запускатели. Твои ресурсы, примеры и лицензия сохранены.

Старые EXE нужно пересобрать. Если игровой проект хранит собственную копию `runtime/engine`, её нужно обновлять отдельно из этого `engine/` вместе со всеми новыми модулями. Этот архив обновляет редактор и общую библиотеку движка.

## Перемещение объектов

Сначала выбери объект. Теперь можно нажимать на поверхность меша, даже если его центр далеко от курсора. Сам выбор не сдвигает объект.

| Действие | Управление |
|---|---|
| Перемещение | W; тяни красную X, зелёную Y или синюю Z |
| Перемещение в плоскости | Тяни цветной квадратик между двумя осями |
| Движение в плоскости экрана | Тяни центральный квадрат или нажми G |
| Ограничить начатое движение | X / Y / Z; повторное нажатие снимает ограничение |
| Ограничить плоскостью | Shift+X — YZ, Shift+Y — XZ, Shift+Z — XY |
| Мировые / локальные оси перемещения | L или кнопка WORLD / LOCAL |
| Привязка | Удерживай Ctrl или включи Snap; кнопки − / + меняют шаг |
| Точное перемещение | Удерживай Shift: десятая часть смещения |
| Подтвердить | Отпусти мышь; после G — щелчок или Enter |
| Отменить текущее движение | Esc или ПКМ; смена сцены / потеря фокуса тоже отменяет |
| Отменить / вернуть завершённое движение | Ctrl+Z / Ctrl+Y: одно движение — одна запись истории |
| Поворот / масштаб | E / R; выбери ось манипулятора |
| Приблизить выбранный объект | F, с учётом его размеров |
| Осмотр | ПКМ — орбита, средняя кнопка — панорама, колесо — приближение |

Привязка считает полное смещение от начала движения: мелкие события мыши не застревают на одном делении. Другие координаты не округляются при движении по одной оси. При взгляде прямо вдоль оси её глубину можно менять вертикальным движением мыши после X/Y/Z. Мировое перемещение правильно переводится в локальные координаты повёрнутого или масштабированного родителя. Поворот и масштаб меняют локальные каналы трансформации. Заблокированные узлы и режим Camera Preview не позволяют перетаскивать объекты.

## Что ускорено

- **Физика 2D/3D:** вместо перебора всех пар строится пространственная сетка. Проверяются соседние тела с сохранением масок, триггеров и прежнего AABB-решателя. Кандидаты упорядочены; сетка обновляется на итерациях решателя. Для огромных коллайдеров есть ограничение числа ячеек и общий список, поэтому большой пол не раздувает сетку. Сигнал входа в триггер не повторяется на каждой итерации.
- **Runtime 3D:** общие примитивы и файловые меши, преобразованные вершины, нормали и центры граней кэшируются. Базис камеры рассчитывается один раз для её текущего состояния. Меши вне камеры отсекаются до обработки граней. Внутри кадра вершины проецируются один раз на меш; полностью видимые меши проходят короткий путь. Постоянное направленное освещение переиспользует расчёт цветов граней.
- **Границы кадра:** полигоны отсекаются по шести плоскостям. Глубина сортировки и туман берутся до бокового отсечения, чтобы большой пол сохранял прежнее положение относительно предметов.
- **Редактор:** использует тот же кэш геометрии и отсечение; топология рёбер готовится один раз, линии передаются QPainter группой. Скрытый родитель скрывает дочерние меши и свет. Во время перетаскивания не пересоздаются дерево сцены и Inspector и не сериализуется вся сцена. История и панели обновляются при завершении.

Кэш учитывает изменения `position.x += ...`, поворот/масштаб родителя, размер меша и переподчинение. Файловые меши проверяются один раз за кадр на путь; при изменении OBJ/STL загружается новая версия. Удалённые узлы не удерживаются кэшем.

Для настройки сетки из кода доступны `engine.settings.physics.broadphase_cell_size_3d` (по умолчанию 4.0) и `broadphase_cell_size_2d` (64.0). Это размеры ячеек в единицах соответствующего мира. Счётчики кандидатов доступны в `engine.physics.stats`, рендера — в `engine.renderer.render_stats`.

## Проверка на своём ПК

Открой `project/scenes/performance_1000.vscene` в редакторе: там 1000 предметов с мешами/коллайдерами, из них 50 динамических, плюс пол, камера и свет. Главная сцена проекта не заменена. Более крупный пример: `python tools/create_stress_scene.py --count 3000`.

Обойди сцену камерой, выбери ближний и дальний меш, попробуй все оси/плоскости, Ctrl-привязку и отмену. Проверь сохранение, перезапуск, Undo/Redo, перемещение ребёнка повёрнутого родителя, P Camera Preview и запуск сцены. Для проверки готового Windows EXE нужна пересборка на Windows.

Автоматические проверки: `python -m pip install Pillow`, затем `python tools/run_checks.py`. Также можно установить QA-зависимости через `pip install -e ".[qa]"`. Результаты и сравнение времени — `VALIDATION_RU.md`. Повторный CPU-замер: `python tools/benchmark_many_objects.py`.

`tools/preview_editor.py` и `tools/preview_runtime.py` создают офлайн-кадры через Pillow. Это проверка логики и композиции, а не запись настоящего окна Qt/SDL.

## Где продолжать работу

| Область | Файлы |
|---|---|
| Сетка кандидатов и решение контактов | `engine/physics/broadphase.py`, `world.py` |
| Общий кэш матриц / мешей / граней | `engine/rendering/cache3d.py` |
| Камера, отсечение и луч курсора | `engine/rendering/projection3d.py` |
| Игровая отрисовка | `engine/rendering/renderer.py` |
| Математика манипулятора | `editor/transform_gizmo.py` |
| Рисование осей, выбор и события мыши | `editor/widgets/viewport3d.py` |
| История одного перетаскивания | `editor/main_window.py` |

В 0.9.0 движок сохраняет программную 3D-отрисовку. Плотная сцена, где видны тысячи сложных объектов, всё ещё требует бюджета геометрии и света. Числа тестового хоста не являются обещанием FPS на твоём компьютере.
