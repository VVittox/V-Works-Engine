# Работа с редактором

Редактор сделан на Qt (PySide6). Слева обычно отображаются **Scene Tree**, справа **Inspector**, центральная область — вкладки **2D Scene**, **3D Scene** и **Game**. Внизу находятся **FileSystem**, **Asset Browser** и панели инструментов.

## Основные действия

| Действие | Как открыть |
|---|---|
| Создать ноду | Scene → Add Node или `Ctrl+A` |
| Новая сцена | File → New Scene |
| Сохранить | `Ctrl+S`; все сцены — `Ctrl+Shift+S` |
| Копировать, вставить, дублировать | `Ctrl+C`, `Ctrl+V`, `Ctrl+D` |
| Отмена и возврат | `Ctrl+Z`, `Ctrl+Y` в зависимости от раскладки и Qt |
| Просмотр 2D / 3D / Game | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` |
| Запустить проект извне | `F5` |
| Запустить текущую сцену извне | `F6` |
| Play In Editor | `Ctrl+F5` |
| Pause / Step | `F7` / `F10` |
| Inspector | Выбор ноды в Scene Tree |
| Консоль | View → Python Console |
| Профайлер | View → Profiler |
| Сигналы | Scene → Signals |
| Привязки ввода | Project → Input Map |

Точные сочетания для отдельных команд видны в меню редактора.

## Изменение 3D-объектов

В 3D viewport используйте Move `W`, Rotate `E`, Scale `R`, **Frame Selected** `F`, preview камеры `P`. Поворот и движение камеры выполняются средствами 3D viewport. Параметры transform также можно редактировать в Inspector — это удобно для точных значений.

## Настройки оформления

В Project Hub нажмите **Editor Settings** или откройте **Edit → Editor Settings**. Доступны:

- темы **Midnight**, **Graphite**, **Ocean**, **Light**;
- цвет интерфейсных акцентов **Blue / Cyan / Violet / Emerald / Orange**;
- размер шрифта **8–18 pt**;
- плотность интерфейса **Compact / Comfortable / Spacious**.

Настройки хранятся в `QSettings` отдельно от игрового проекта и применяются ко всем окнам. Раскладка dock-панелей и размер окна редактора сохраняются при закрытии и восстанавливаются при запуске. `View → Reset Editor Layout` сбрасывает раскладку. Часть старых виджетов использует собственную отрисовку: тема не меняет цвета содержимого игровой сцены.

## Панели

**Scene Tree**: вложенность, выделение и перетаскивание дочерних нод. **Inspector**: свойства выбранной ноды, скрипты, параметры физики и рендера. **FileSystem**: файловая система проекта. **Asset Browser**: просмотр и открытие ресурсов. **Game View**: встроенное выполнение игры. **Output / Diagnostics / Console / Profiler**: диагностика и анализ. **TileMap / Navigation**: инструменты специализированных 2D-нод.

## Восстановление

В Project Settings настраивается автосохранение. `File → Autosave / Recovery` позволяет увидеть точки восстановления. Перед крупными изменениями сцен сохраняйте ручную копию проекта.
