# Ресурсы и импорт ассетов

В редакторе есть FileSystem, Asset Browser и **Import Assets**. Файлы обычно хранятся внутри `assets/` проекта, чтобы относительные пути сохранялись при экспорте. Некоторые типы ресурсов имеют собственный редактор или отдельный формат.

## Структура ассетов

- `assets/textures/`: изображения и текстуры.
- `assets/audio/`: аудиофайлы.
- `assets/materials/`: ресурсы материалов, в примере есть `.vmat`.
- `assets/shaders/`: 2D-шейдеры, в примере `.vshader`.
- `assets/prefabs/`: многократно используемые деревья нод.
- `assets/tilesets/`: настройки тайлов, в примере `.vtileset`.

## Порядок импорта

1. Откройте File → Import Assets.
2. Выберите файл и подходящую категорию.
3. Разместите текстуру в `Sprite2D.texture_path` или укажите `MeshInstance3D.mesh_path` для поддерживаемого 3D-формата.
4. Проверьте относительный путь в Inspector.
5. Сохраните сцену, запустите Game View, убедитесь, что файл доступен runtime.

## Материалы и шейдеры

Resources → New Material, New Shader, New TileSet открывают генераторы соответствующих данных. Редактор ресурсов хранит свойства в файлах проекта. Работа с 2D-шейдерами не означает, что уже имеется полный GPU PBR-пайплайн для 3D: эта область находится в разработке.

## Форматы 3D

В исходниках присутствуют загрузчики/импорт для некоторых меш-форматов, включая OBJ и STL. Полезно начинать с low-poly геометрии. Перед использованием сложных моделей проверьте ориентацию осей, масштаб, нормали и поддержку материалов. Нет гарантии полной совместимости с экспортом Unity/Unreal или сложными glTF-сценами.

## Если ресурсы пропали в сборке

Проверьте, что ресурсы находятся внутри папки проекта и доступны через относительные пути. Посмотрите содержимое `builds/` и экспортный manifest. Абсолютные пути (например, `C:\Users\...`) не переносимы между компьютерами.
