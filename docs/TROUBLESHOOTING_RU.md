# Отладка и решение проблем

## Редактор не запускается

Проверяйте текущую папку: файл `launch_editor.py` должен лежать рядом с `engine/` и `editor/`. Установите зависимости той версией Python, которой запускаете редактор. Для диагностики используйте PowerShell: `.\.venv\Scripts\python.exe launch_editor.py`.

## `ModuleNotFoundError: PySide6` или `pygame`

Выполните `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`. Если `pip` пишет о сетевой ошибке, сначала проверьте интернет/DNS и настройки индекс-сервера. Без GUI-зависимостей редактор не откроется.

## Game View пустой

Проверьте, что существует `main_scene` и она включена в Build Scenes. Для 3D нужны активная `Camera3D` и видимая геометрия; для 2D — подходящая 2D-камера или экранные объекты. Проверьте режим предпросмотра в Project Settings → Runtime.

## Камера не показывает объект

Проверьте FOV и near/far, видимость меша, положение относительно камеры, признак `current`, `cull_mask`. В 3D viewport используйте `F` для кадрирования выделенной ноды.

## Проблемы с GPU

Если ModernGL не создаёт OpenGL-контекст, движок переходит на CPU. Проверьте версии видеодрайвера и `requirements-gpu.txt`, включите отладочный вывод и повторите тест на `3d_showcase.vscene`.

## Скрипт не выполняется

Проверьте `scripts/<имя>.py`, регистр имени класса `Script`, наследование от `VScript`, относительный `script_path`. Включите `strict_scripts` для диагностики. Ошибки скриптов могут происходить ещё до первого кадра.

## Пропадают изменения интерфейса

Оформление и раскладка сохраняются через `QSettings` в профиле пользователя, **не** в `project.vproject`. Обновите настройки в Editor Settings и закройте редактор нормальным способом, чтобы сохранить расположение окон.

## Если один EXE не работает

Запустите `build_editor_onedir_debug.bat`. В однопапочной сборке легче увидеть ошибки импорта и отсутствующие Qt-плагины. Не удаляйте `_internal/` у onedir debug build. В onefile это содержимое упаковано внутрь exe.

## Полезные тесты

`python -m pytest -q tests` (нужны зависимости из `requirements.txt`). Для структуры сцен используйте `tests/test_core.py` и `tests/test_new_features.py`. Если выполняете тесты без графического окружения, графические проверки могут не стартовать.
