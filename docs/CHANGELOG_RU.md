# Изменения V Works Engine 0.11-preview

## Добавлено

- Общие настройки внешнего вида редактора и Project Manager: Midnight, Graphite, Ocean, Light.
- Пять акцентных цветов; 8–18 pt шрифт; три уровня плотности интерфейса.
- Сохранение расположения dock-панелей и геометрии окна через QSettings.
- Поиск по последним проектам в Project Hub и подробные описания шаблонов.
- 12 новых сцен-шаблонов в дополнение к 7 исходным: всего **19**.
- `TEMPLATE_GUIDE.md` для каждого создаваемого проекта.
- `build_editor_onefile.bat` и `V Works Engine Onefile.spec` для Windows onefile/windowed с иконкой.
- `build_editor_onedir_debug.bat` для диагностики Windows-сборки.
- Комплект русскоязычной документации в `docs/`.
- Удалены комментарии Python через токенизацию без изменения строковых литералов.

## Унаследовано от прошлой сборки

- 2D/3D сцены, физика, импорт ресурсов и редакторские инструменты.
- CPU-3D и экспериментальный OpenGL 3.3 GPU-рендер.
- Path3D, PathFollow3D, LookAt3D и UI-ноды.
- Существующий экспорт Windows-игр, macOS-подготовка и Android source bundle.

## Ограничения

- Запуск Qt GUI и компиляция Windows EXE **не проверены** в текущем Linux-окружении без PySide6/pygame.
- Дополнительные 3D-шаблоны — готовые сцены для изучения, а не завершённые игровые механики.
- Android: исходный пакет, не APK. macOS: требуется сборка на Mac.
- GPU: не полностью GPU-native рендер, скорость зависит от сцены и readback.

## Проверки

Выполняются независимые проверки целостности синтаксиса Python, отсутствия Python-комментариев, правильности сохранения и загрузки всех 19 шаблонов. Полные GUI smoke-тесты необходимо запустить на целевом компьютере.
