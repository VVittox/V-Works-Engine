# V Works Engine — сборка исходников 0.11-preview

**Это готовый ZIP с исправленными и расширенными исходниками, но не готовый Windows EXE.**

Содержимое было собрано из последнего `V Works Engine(2).zip` и недостающего ядра предыдущего `V_Works_Engine_0_10_Preview.zip`. Обновления редактора и ресурсов из последнего архива имеют приоритет.

## Что нового

- 19 стартовых шаблонов проектов с `TEMPLATE_GUIDE.md`.
- Новые темы, цветовые акценты, масштаб шрифта и плотность UI.
- Запоминание расположения dock-панелей и размеров окна редактора.
- Поиск в списке последних проектов.
- Исходный Python-код очищен от комментариев.
- Полный пакет документации `docs/` и новый `README.md`.
- `build_editor_onefile.bat` + `V Works Engine Onefile.spec`: один Windows EXE с иконкой без консоли.
- `build_editor_onedir_debug.bat`: сборка с консолью для отладки.

## Запуск

На Windows выполните `start_editor.bat` (после установки зависимостей) либо `py -3.12 -m venv .venv`, затем `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` и `.\.venv\Scripts\python.exe launch_editor.py`.

## Сборка редактора в EXE

На Windows запустите `build_editor_onefile.bat`. Результат должен появиться в `dist/V Works Engine.exe`. Не путайте эту сборку редактора с **Build Windows** в меню экспорта игры.

## Документация

Откройте `docs/INDEX_RU.md` — там находятся полные инструкции по запуску, редактору, темам, шаблонам, нодам, 2D/3D, скриптам, ассетам, плагинам и сборкам.

## Честное ограничение

В этой среде недоступны PySide6/pygame, Windows PyInstaller и реальный GPU-драйвер. Поэтому текущая проверка охватывает структуру и тестовое создание проектов, но не обещает проверенного поведения GUI/Windows EXE. Android source bundle ещё не APK.
