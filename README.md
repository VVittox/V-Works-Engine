# V Works Engine

**V Works Engine - мой игровой движок на Python для создания 2D и 3D игр.**

Я делаю его для себя и для тех, кто хочет попробовать разработку игр, но не знает, с чего начать. Здесь есть редактор, сцены, игровые объекты, скрипты и примеры проектов, с которыми можно экспериментировать.

Сейчас движок находится на стадии **0.11 Preview**. Я продолжаю его дорабатывать, поэтому некоторые функции ещё могут работать не так, как хотелось бы.

## Зачем я делаю этот движок

Мне нравится не только делать игры, но и разбираться, как работают сами игровые движки. Так появился V Works Engine.

Я хочу, чтобы на нём можно было собрать свою первую игру, разобраться со сценами и объектами, написать логику на Python и увидеть результат прямо в редакторе. При этом мне самому интересно постепенно добавлять новые инструменты и проверять их в настоящих проектах.

Движок открытый, так что можно посмотреть его код, попробовать что-то изменить и разобраться, как всё устроено внутри.

## Что уже есть

В V Works Engine можно:

- Создавать 2D- и 3D-сцены и собирать их из нод.
- Настраивать объекты через Inspector, работать с деревом сцены и сохранять изменения.
- Писать игровую логику на Python и обрабатывать события и сигналы.
- Работать со спрайтами, звуками, материалами и другими ресурсами.
- Использовать 2D/3D-физику, коллизии, камеры и освещение.
- Делать интерфейсы, карты TileMap и простые эффекты.
- Создавать проект из шаблона, а затем переделывать его под свою идею.
- Пробовать CPU-рендеринг и экспериментальный OpenGL-режим для 3D.

Это ещё не законченный движок. Особенно активно я работаю над редактором, 3D и производительностью. Если какая-то функция ведёт себя странно, вполне возможно, что она ещё в разработке.

## Как запустить

Для запуска из исходников понадобится Python. Для Windows рекомендую **Python 3.12**.

Сначала скачай репозиторий:

```bash
git clone https://github.com/VVittox/V-Works-Engine.git
cd V-Works-Engine
```

### Windows

Можно использовать `setup_windows.bat` и `start_editor.bat`. Или установить зависимости вручную:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launch_editor.py
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python launch_editor.py
```

Для экспериментального GPU-режима отдельно установи зависимости из `requirements-gpu.txt`. Нужны подходящий драйвер и поддержка OpenGL 3.3.

Если редактор не запускается, загляни в [инструкцию по установке](docs/GETTING_STARTED_RU.md) или [раздел с частыми проблемами](docs/TROUBLESHOOTING_RU.md).

## С чего начать

Если ты впервые открыл V Works Engine, советую не начинать со сложной 3D-игры. Сначала попробуй сделать что-нибудь простое.

1. Запусти редактор и выбери **Create Project**.
2. Создай проект по шаблону **2D Starter**.
3. Открой сцену `scenes/main.vscene` и посмотри, какие ноды в ней находятся.
4. Выбери объект в Scene Tree и попробуй изменить его параметры в Inspector.
5. Запусти сцену, потом добавь свой объект или скрипт.

Когда разберёшься с основами, попробуй **2D Platformer**, **3D Starter** или **3D Physics Lab**. Всего сейчас есть **19 учебных шаблонов**. В проектах, созданных из шаблонов, есть файл `TEMPLATE_GUIDE.md` с пояснениями.

Также в папке `example_projects/` лежат готовые примеры, которые можно открыть через **Open / Import Folder**.

## Пример настоящей игры

Я перенёс свою игру **[VVittox Survival](https://github.com/VVittox/VVittox-Survival)** с Unity на V Works Engine.

Это не просто демонстрационная сцена. На её исходниках можно посмотреть, как я организую ресурсы, сцены и скрипты в игровом проекте. Можешь скачать игру, открыть её через редактор и попробовать что-то изменить.

Мне хочется, чтобы по таким примерам было проще учиться работать с движком, а не только читать документацию.

## Что находится в репозитории

```text
V-Works-Engine/
├── editor/             # редактор движка
├── engine/             # игровая логика и основные системы
├── example_projects/   # учебные проекты
├── examples/           # примеры на Python
├── project/            # демонстрационный проект
├── docs/               # документация
├── tests/              # тесты
├── tools/              # вспомогательные инструменты
├── launch_editor.py    # запуск редактора
├── requirements.txt    # основные зависимости
└── requirements-gpu.txt
```

Если интересно, как устроен сам движок, начни с `engine/`. Если хочешь посмотреть, как работает редактор, открывай `editor/`. А если твоя цель просто сделать игру, сначала лучше изучить `example_projects/` и документацию.

## Что пока стоит учитывать

V Works Engine ещё развивается, поэтому перед обновлением лучше сохранять копию своих проектов.

3D-рендеринг через OpenGL пока экспериментальный: часть обработки выполняется на CPU, и производительность зависит от сцены и компьютера. Сборка Windows EXE выполняется на Windows, а `.app` для macOS нужно собирать на Mac. Подготовка исходников для Android ещё не означает готовый APK.

Я не хочу обещать, что всё будет работать идеально на любой системе. Если столкнулся с проблемой, напиши, на какой системе запускаешь движок и что именно произошло.
